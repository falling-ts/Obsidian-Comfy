# Obsidian-Comfy

为故事库的 md 数据表提供阅读体验增强，并打通 ComfyUI `output` 目录的资源引用。

面向 [stories](../../) 仓库（vault = `D:\Comfy\stories`）开发，桌面版专用。

## 功能

### 1. 表格增强（第一列是 `ID` 的表格）

- **单行渲染**：所有列与内容强制单行，绝不换行
- **省略号截断**：列为 `TEXT` 类型（表头形如 `主-正词(TEXT)`）时，超长内容在渲染层用 `...` 截断，**md 源码完全不变**
- **横向滚动**：表格超宽时容器横向滚动，滚动条细样式
- **搜索过滤**：表格上方搜索框，按 ID 或任意字段实时过滤
- **完整分页**：每页数量选择（20/50/100/200/全部）、首页、上一页、页码、下一页、尾页、跳转输入框
- **ID 排序**：点击 `ID` 列表头或工具栏 `ID ↑/↓` 按钮切换增序 / 降序（按 ID 开头的数字排序，5 位插入编号也能正确排序）

### 2. `@` 资源引用弹窗

在编辑器里输入 `@` 时自动弹出 `output` 目录浏览器：

- 只列出**普通文件**与**「数字-」/「数字_」编号目录**（如 `0040_文生视频`），跳过 `3d`、`clipspace` 等非编号目录与隐藏项
- 文件带**缩略图**：图片显示缩略图、视频显示首帧、音频显示音符图标
- 显示文件类型标签与大小
- 可进入编号目录选择其中的文件，也可返回根目录
- 过滤框按文件名筛选，双击条目直接确定
- 点「确定」自动插入引用：子目录文件插入 `@{目录名/文件名}`，根目录文件插入 `@{文件名}`（**均为去掉扩展名的写法**，符合故事库 ID 引用规范）

### 3. 双击编辑单元格

双击数据格会按**该列声明的类型**分派到对应编辑器，写回时**只替换那一格**，同行其它格与文件其它内容一个字节都不动：

| 列类型 | 双击行为 |
|--------|----------|
| `IMAGE` / `VIDEO` / `AUDIO` / `MASK` | 弹出与 `@` **完全相同**的 output 文件浏览器，选中后把 `@{目录名/文件名}` 写回该格 |
| `INT` / `FLOAT` | 该格就地变成输入框（初值取自源文件），**失焦或回车**写回；`Esc` 取消，非法数值会被拒绝且不写盘 |
| `TEXT` | 弹出多行文本编辑器（`<br>` 显示为真实换行，保存时转回 `<br>`），`Ctrl/Cmd+Enter` 保存 |
| 未声明类型（默认 `STRING`） | 同 `TEXT`，走多行文本编辑器 |

细节：

- 写回用**绝对字符区间替换**，并在写盘回调里**重新定位**一次，因此弹窗开着时文件被别处改动也不会写错位置
- 该格原有的首尾空白写法（表格对齐用的空格）会被保留
- `TEXT` 单元格里的字面 `<br>` 在**渲染层**原样保留（md 源码不变，仅靠 CSS 隐藏成单行截断），而在**编辑框**里会显示成真实换行：直接回车即可分段，粘贴的多行文本也按行显示；保存时**只把换行转回 `<br>`**（`<br>` / `<br/>` / `<br />` / `<BR>` 一律归一成小写 `<br>`，CRLF/CR 一并归一），其余字符一个都不动，于是单元格永远保持单行、表格形状不被破坏
- 保存后该格显示立即同步，不必手动重载

> 与表格增强一样，仅在**阅读模式**下生效。

### 4. 引用原文还原（`@{...}` 里的下划线）

`@{表名_编号/行ID_名称}` 这种整格引用天然带两个下划线，Markdown 会把它们当成 `_强调_`：渲染结果吃掉两条下划线、中间那段变斜体（下划线紧挨中文时 Obsidian 判定「词内下划线」失效，属其[已知问题](https://forum.obsidian.md/t/commonmark-compliance-reader-should-not-parse-intra-word-underscore-cjk-and-cyrillic/42174)）。**md 源码没有被改动**，坏的只是显示。

插件按固定约定 `@{(数字)(名字)/(数字)(名字)}` 把原文补回：只把那个 `<em>` 换回字面文本 `_内容_`，单元格其余子节点一个不动；已经渲染正确的格子直接跳过，因此可重复执行。

- **阅读模式**：后处理器拿到整个块，逐个单元格还原
- **编辑模式的实时预览**：Obsidian 的表格 widget 对**每个单元格**各跑一次后处理器，同一条逻辑照样生效（表格增强本身仍只在阅读模式生效，见「使用前提」）

## 安装

插件源码在本目录；Obsidian 从 `.obsidian/plugins/` 读取插件，因此需要在此建立链接：

```powershell
# 在 vault 根目录 (stories) 下执行
cmd /c mklink /J ".obsidian\plugins\obsidian-comfy" "Obsidian-Comfy"
```

并在 `.obsidian\community-plugins.json` 中启用：

```json
[
  "obsidian-comfy"
]
```

首次打开 vault 时 Obsidian 会询问「是否信任这个仓库的作者」，需选择**信任仓库作者并启用插件**（否则处于安全模式，插件不加载）。

修改 `main.js` / `styles.css` 后，用命令面板执行「重新加载 Obsidian」即可生效。

## 使用前提

- **阅读模式**：表格增强走 `registerMarkdownPostProcessor`，**只在阅读模式（Ctrl+E 切换）生效**，实时预览模式下表格仍是原生渲染。
- **两种模式都生效**：引用原文还原（`@{}` 下划线补回）——实时预览的表格 widget 对每个单元格单独跑一次 markdown 后处理器，所以同一段逻辑在阅读模式与实时预览下都会命中。
- **桌面版**：插件通过 Node `fs` 读取 vault 外的 ComfyUI output 目录，故 `isDesktopOnly: true`。

## 设置

设置 → 第三方插件 → Comfy 数据表：

| 项 | 说明 | 默认 |
|---|---|---|
| output 目录 | ComfyUI 的 output 绝对路径 | `D:\Comfy\media\七纹刻印` |
| 启用表格增强 | 总开关 | 开 |
| 启用 @ 弹窗 | 总开关 | 开 |
| 每页数量可选项 | 逗号分隔 | `20,50,100,200` |
| 默认每页数量 | 0 表示全部 | `20` |
| TEXT 列最大宽度 | 超出即截断 | `420` |
| 其它列最大宽度 | 非 TEXT 列上限 | `720` |
| 缩略图取图方式 | `app`（`app://local` 协议）/ `base64`（内联，兼容性最好但占内存） | `app` |
| 弹窗缩略图宽度 | 像素 | `72` |

## 实现要点

- **省略号截断为什么不用 `td` 的 `max-width`**：在 `table-layout: auto` 下 `td` 的 `max-width` 不生效，因此单元格内容会被包进 `.oc-clip` 容器，由该容器承担 `max-width` + `overflow: hidden` + `text-overflow: ellipsis`。
- **排序为什么要重排 DOM**：`apply()` 先按当前查询过滤、再按 ID 数字键排序，然后**按排序结果**依次 `appendChild` 回 `tbody`；若按原始顺序重排会覆盖排序结果。
- **ID 列点击用事件委托**：挂在滚动容器上并判断 `closest('th.oc-th-id')`，避免 Obsidian 重渲染表格后节点句柄失效。
- **`@` 触发**：借用 `EditorSuggest.onTrigger` 做按键检测（比 CodeMirror 扩展简单且准确），命中后直接打开自定义 `Modal` 并返回 `null`，因此不会显示候选列表。

- **`@{...}` 下划线还原怎么同时覆盖预览与编辑**：实时预览的表格是 Obsidian 自己的 CM6 widget，它渲染单元格时会把单元格内容交给 `MarkdownPostProcessor` 注册表（`el` = 单元格内的 `.table-cell-wrapper`），所以不必写 CM6 装饰器，同一个后处理器在两种模式下都会被调用；还原只认「整格是 `@{数字…/数字…}` 且下划线确实被吃掉（存在唯一 `<em>`）」，对正常渲染与真正的斜体文本都不动手。

## 文件

| 文件 | 说明 |
|---|---|
| `manifest.json` | 插件清单 |
| `main.js` | 插件全部逻辑（纯 JS，无构建步骤、无第三方依赖） |
| `styles.css` | 表格与弹窗样式 |

插件不引入任何 npm 依赖，也不需要打包——`main.js` 直接由 Obsidian 以 CommonJS 加载。
